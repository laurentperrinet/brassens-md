### Notes

 * Accords sur la syllabe chantée (Beausoleil, ChordPro) : http://beausoleil.free.fr/GB.Colombine.php?titre=Colombine
 * Couplets en la mineur (Am, Am+, Am6, G7), arrangement conservé ; Beausoleil reste en si majeur (B, G#m7, E, F#7, C#7) de l'intro à l'outro, avec les tenues finales détaillées.
 * Structure (PDF d'Hervé Milhau, 2017-11-29) : intro de quatre lignes `C Am7 F G7 / C Am7 D7 G7 / C Am7 F G7 / C Am7 D7 G7 C` (ici transposée d'un demi-ton plus bas, avec les « pam pam »), puis cinq couplets de six vers ; le solo de guitare vient avant le dernier couplet, quatre lignes `Eb Cm7 Ab Bb7 / Eb Cm7 F7 Bb7 / Eb Cm7 Ab Bb7 / Eb G7`, soit `D Bm7 G A7 / D Bm7 E7 A7 / D Bm7 G A7 / D F#7` dans la tonalité ci-dessus.
 * Harmonisation : Milhau (en do) écrit le couplet `C Am7 F / G7 C / Am7 D7 G7` là où la version ci-dessus (Beausoleil) joue la descente chromatique `Am Am+ Am6 G7` ; le dernier accord du morceau est `C`.
 * Les syllabes étirées sont coupées dans le PDF comme dans la chanson : « pu - ce », « Capu - ce », « Mas - que », « Fantasque », « cha - ttes », « ju - pes », « du - pes ».
